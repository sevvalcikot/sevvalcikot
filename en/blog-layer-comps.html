Using Layer Comps in Photoshop

The tidiest way to keep several states of a web UI in a single PSD file: Layer Comps.

Tags

In my Graphic Animation I class I designed the homepage interface of a bank website in Photoshop. As the design grew, I needed to show different states of the same page (menu open, menu closed, a different banner). Instead of saving a separate file for each state, I used Layer Comps.

What are Layer Comps?

A layer comp takes a "snapshot" of the current state of your layers. It remembers each layer's visibility, position and layer styles (like shadows or strokes). This lets you keep many design options inside one PSD file and switch between them with a single click.

How I used it

  1. I opened the panel with Window → Layer Comps.
  2. After preparing the first state of the page, I clicked "Create New Layer Comp" and chose what it should remember: Visibility, Position and Appearance.
  3. I changed the banner and the menu, then created a second comp.
  4. I switched between the comps to compare the states.
  5. Finally I exported every state as a separate image with File → Export → Layer Comps to Files.

Why it works

I no longer toggle layers on and off one by one, and I can try new ideas without fear of breaking an option. Presenting several options to a teacher or a client becomes much easier. Giving clear names to layers and groups was the biggest help with this method.
